0 · 两张图分别在问什么

这两张图是同一批数据的两道不同问题。先记住各自的"一句话"，再看步骤就不会迷路。

Fig 2a —— 体检：两层数据对不对得上

输入：RNA 矩阵 + ATAC 矩阵（不需要基因组序列）

问题：RNA 说这是 A 类细胞，ATAC 也说它是 A 类细胞吗？

怎么读：

  • 行 = 一套细胞类型，列 = 另一套细胞类型
  • 对角线必须最亮——这是质检项，自己跟自己比当然最像
  • 非对角线上的亮块 = 这两类细胞在两层里都像（比如叶和旗叶的同一类细胞）
  • 成片的暗带 = 两层"对不上"，即论文说的 divergent patterns

结论：叶 / 旗叶的叶肉、维管、保卫、表皮 → 高相关；种子表皮 → 中等相关。说明转录后调控（含 mRNA turnover）的贡献高度细胞类型特异。

一句话：2a 证明这套多组学数据是自洽的——不是两个独立实验硬拼起来的。

Fig 2b —— 查名单：这些开放区是谁在管

输入：ATAC 矩阵 + 基因组 DNA 序列（比 2a 多了这一样）

问题：某类细胞特异开放的染色质区域上，坐着哪些 TF？

怎么读：

  • 横轴 = 细胞类型，纵轴 = TF 的 motif（按 36 个家族成块排列）
  • 颜色 = 富集程度，0 浅蓝 → 50 橙 → 100 黄
  • 大片浅蓝是正常的（绝大多数 TF 和绝大多数细胞类型没关系）
  • 要读的是哪里不蓝：对角线上的黄块、最左一列上半段的整条黄

结论：平均每类细胞显著富集 17 个 motif（Fisher 精确检验，FDR < 0.01）；叶肉最多，24 个。

一句话：2b 是从字母里读名单——DNA 串上没有 TF，只有 motif 的痕迹，所以"谁在管"永远是推断。

两张图的关系

2a 先确认"数据可用"（两层同步），2b 才敢开始挖"机制"（谁在调控）。顺序不能反——如果两层对不上，那么基于 ATAC 推出来的调控网络就没有 RNA 证据支撑。这也是论文把 2a 和 2b 放进同一个图的原因：先立证据基础，再讲发现。

ATAC 侧：先找 marker peak，再求平均，再算相关

06 号 · 第 38–80 行
DefaultAssay(rice.sub) <- "ATAC"

rice.sub.atac.markers <- parallel::mclapply(
    unique(rice.sub$tissue_cluster), function(x) {
        xx <- FindMarkers(
            rice.sub,
            ident.1              = x,
            only.pos             = T,
            test.use             = "LR",
            max.cells.per.ident  = 300,
            latent.vars          = "nCount_ATAC"
        )
        data.frame(xx, gene = rownames(xx), cluster = x)
    }, mc.cores = 20)

peaksID <- do.call(rbind, peaks) %>%
    group_by(cluster) %>% top_n(500, avg_log2FC) %>%
    pull(gene) %>% unique()

rice.sub.atac.avg <- AverageExpression(rice.sub, assays = "ATAC", features = peaksID)
corATAC <- cor(rice.sub.atac.avg$ATAC, method = "pearson")

四个参数各有理由：

参数为什么这么设
test.use = "LR"逻辑回归。比默认的 Wilcoxon 慢，但对 ATAC 这种极稀疏数据更合适
latent.vars = "nCount_ATAC"把测序深度当协变量扣掉，避免"测得深所以显得开放"
max.cells.per.ident = 300每簇最多取 300 个细胞：既提速，又防止超大簇主导结果
mc.cores = 2056 个簇逐个跑太慢，并行
检查点
  • length(rice.sub.atac.markers) 应等于簇数
  • length(peaksID) 在几千量级（56 簇 × 500 去重后）
  • dim(rice.sub.atac.avg$ATAC) 的行数 = length(peaksID)
偏差排查
  • do.call(rbind, peaks) 报错 → 有簇返回了 NULL；脚本里 lapply 中那句 if (!is.null(nrow(x))) 就是防这个的，别删
  • 某些簇静默消失（细胞太少，FindMarkers 返回空）→ 最终热图列数会少于 56。这是"不报错但结果不对"的典型，务必打印 unique(...$cluster) 对一遍
  • Windows 上 mclapply 不并行（mc.cores 无效）→ 换 parallel::parLapply 或直接降 cores 串行跑

跨层相关：这里换成 Spearman

06 号 · 第 99–102 行
colnames(atacRNA.avg$atacRNA) <-
    paste(colnames(atacRNA.avg$atacRNA), "ATAC", sep = "-")

atac_RNA.cor <- cor(
    atacRNA.avg$atacRNA,
    rice.sub.avg$RNA[rownames(atacRNA.avg$atacRNA), ],
    method = "spearman"
)

为什么必须换 Spearman

  • 量纲不同：RNA 侧是 UMI 计数归一化值，atacRNA 侧是信号加总值
  • 分布偏斜：RNA 表达量极度右偏，少数高表达基因会主导 Pearson 的方差
  • Spearman 只看排名，只要求"单调"，对量纲和极端值都免疫

⚠️ 最容易踩的隐形坑：cor() 按位置对齐，不按名字

所以必须写 [rownames(atacRNA.avg$atacRNA), ] 手动把 RNA 矩阵的行顺序对齐。忘了写的话——不会报错，只是算出一堆错配的相关性。这属于"看起来正常但其实是错的"，比报错危险得多。

检查点
  • range(atac_RNA.cor) 大致 0 ~ 0.6（跨层相关性天然偏低）
  • 对角线是每行/每列的最大值
偏差排查
  • 整体数值只有 0.05 左右 → 忘了换 Spearman，还在用 Pearson
  • 对角线不是最高 → 行没对齐（上面那个坑）
  • 矩阵出现大量负值 → 两边基因集不一致，被 0 填充了

结果自查：逐条对照论文

论文 p724 正文

论文原文（可直接引用）：

“Comparing scRNA and scATAC revealed surprisingly divergent patterns of chromatin accessibility and gene expression in some cell types (Fig. 2a …). Although we found high correlation in the mesophyll, vascular, guard cell and epidermis from leaf and flag leaf, we observed more moderate correlation between gene expression and ATAC, for example, in the epidermis of seeds. This demonstrated that the contribution of post-transcriptional regulation, including mRNA turnover, is strongly cell-type specific…”

逐条核对清单
  • 对角线整体深红 ✓
  • 叶 / 旗叶的叶肉、维管、保卫、表皮 → 对角线上出现成片深红块
  • 种子表皮 → 中等相关（明显比上面几类暗）
  • 中间出现两大片蓝色十字带 → 就是论文说的 divergent patterns
如果结论方向反了
  • 对角线上有暗格 → 该簇的 ATAC 侧 peak 数太少，平均谱不稳
  • 整个矩阵一片黄没有结构 → 求平均前没归一化（高表达基因主导，所有簇看起来都像）

3 · Fig 2b 复现：8 步

先明确 Fig 2b 的"颜色"到底是什么

论文图注写的是：“The enrichment was represented by the average deviation scores in the top 2,000 ACRs for each cell type.”

而正文里"平均 17 个 motif 显著富集"这个数字来自 FindMotifs 的 Fisher 精确检验。

这是两套不同的计算，别混。颜色 = chromVAR 偏离分（经缩放）；"17 个"= Fisher 检验显著个数。答辩时被问到"图上的颜色代表什么"，答错就露怯了。

  • 有簇返回 NULL → 最后那句 [!sapply(..., is.null)] 会把它静默删掉，导致最终热图列数少于 56。这是"不报错但结果不对"，务必数一遍
  • names(...) 赋值长度不匹配 → 删掉 NULL 之后名字会对错位，注意脚本里是先赋名再删 NULL（顺序反了会错位）

筛出"你的开放区" + GC 匹配背景（最讲究的一步）

    dplyr::filter(p_val < 0.05, avg_log2FC > 0.5) %>%
    pull(gene)

    top.da.peak <- rice.sub.atac.markers[[cluster]] %>%
        top_n(300, avg_log2FC) %>% pull(gene)
}

peaks.matched <- MatchRegionStats(
    meta.feature  = meta.feature[open.peaks, ],     # 候选池
    query.feature = meta.feature[top.da.peak, ],    # 查询集 = 你的开放区
    n = 50000                                       # 挑 5 万段 GC 匹配的区域
)

① 三个集合分别是什么

名字含义作用
open.peaks该类细胞里所有可及的 peak候选池——背景只能从这里挑
top.da.peak其中差异最显著的那些 peak查询集 = "你的开放区"
peaks.matched从候选池里挑出 5 万段 GC 含量分布与查询集一致的区域背景（对照组）

注意：背景是"另外的区段"，不是开放区自己。两者来自同一个基因组（同一份 DNA），但是不同坐标的区域。而且不能挑一模一样的序列——序列完全相同的话，motif 计数必然相同，比值恒为 1，什么都测不出来。

② 为什么背景必须 GC 匹配

  • G–C 之间有 3 个氢键，A–T 只有 2 个 → 容易解开的开放区天然偏 AT
  • 如果背景的 GC 组成和开放区差很多，那"差异"里就混进了字母组成的贡献，而不是 TF 结合的贡献
  • 结果：GC 相关的 motif 会假性富集或假性耗竭
  • 类比：比较两个班的成绩，得先保证考的是同一份卷子。GC 含量就是那份卷子。
检查点
  • length(top.da.peak) 几百到两千量级（太少会触发兜底）
  • length(peaks.matched) = 50000
  • 关键校验：mean(meta.feature[peaks.matched, "gc"]) 应非常接近 mean(meta.feature[top.da.peak, "gc"])
偏差排查
  • peaks.matched 不足 5 万 → 候选池里 GC 匹配的区域不够，调小 n 或放宽匹配
  • 所有 motif 都"显著" → 背景没匹配上 GC，或下一步忘了传 background =
  • 报 gc 列不存在 → 回到第 2 步检查 meta.features

6 · 答辩问答准备

Q1 · Fig 2a 和 Fig 2b 需要的数据有什么本质不同？
2a 只需要两个矩阵（RNA + ATAC）；2b 额外需要 基因组 DNA 序列，因为 motif 是序列模式，不读序列就无从匹配。这是两张图在数据依赖上最根本的差别。
Q2 · 为什么 Fig 2a 要算两遍（层内 + 跨层）？
层内相关（RNA vs RNA、ATAC vs ATAC）是质检：确认同层内细胞类型分得开（对应 Extended Data Fig 3f）。跨层相关才是科学问题：确认两层对同一批细胞的判断一致——这是后续所有调控分析的前提。
Q3 · 跨层为什么必须用 Spearman？
三个理由：① 两边量纲不同（UMI 计数归一化值 vs 信号加总值）；② RNA 表达量极度右偏，少数高表达基因会主导 Pearson 的方差；③ Spearman 只看排名，只要求单调，对量纲和极端值都免疫。
Q4 · Fig 2b 的背景为什么必须做 GC 匹配？
G–C 有 3 个氢键、A–T 只有 2 个，所以容易解开的开放区天然偏 AT。如果背景的 GC 组成和开放区差很多，算出的"差异"里就混进了字母组成的贡献，导致 GC 相关 motif 假性富集或假性耗竭。GC 含量在这里就是个混杂因素，必须像"比较两个班成绩要先保证同一份卷子"那样先匹配掉。
Q5 · Fig 2b 的颜色代表什么？和正文的"17 个"是一回事吗？
不是一回事。颜色是 chromVAR 的平均 deviation score（论文图注原文）；而"平均 17 个 motif 显著富集"来自 FindMotifs 的 Fisher 精确检验（FDR < 0.01）。两套计算都在 07 号脚本里，但含义不同。
Q6 · 这套分析最大的推断风险是什么？
三个矩阵里没有一个测到了蛋白质。ATAC 测 DNA 开放程度，RNA 测 mRNA，而 TF 本身是蛋白质。所以"某 TF 在管这片区域"永远是推断。这也解释了论文为什么要层层加固证据：2b motif 富集（猜）→ 2d 富集 vs 表达量（自洽）→ 2f–h 网络 + 虚拟敲除（因果模拟）→ 2k–q 突变体（湿实验落地）。
Q7 · 为什么求平均前一定要先归一化？
每个细胞的测序深度不同，不归一化的话测得深的细胞会主导平均值。而且原始计数里高表达基因（核糖体、光合相关）方差天然更大，它们又几乎在所有细胞类型里都高，结果就是所有簇看起来都像，块状结构被抹平。注意：这里出问题的表现不是报错，而是"看起来正常但其实是错的"。
