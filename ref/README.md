# `ref/` —— 从原论文图版反演出来的小参考表

这个目录放的是**从论文原图（矢量图层 / 位图）反向提取出来的小数据表**，用来：

1. 让复现图和原图使用**完全相同的配色**（而不是"看起来差不多"的自选色）；
2. 提供**逐格数值基准**，用来量化"复现得有多准"（Spearman / MAE）。

体积都在几十 KB 量级，所以随仓库一起提交 —— 这样评审者 clone 下来就能直接跑出配色一致的图，不用回头去原图里抠颜色。

---

## 1. 已提交的文件

| 文件 | 内容 | 怎么来的 | 被谁用 |
|---|---|---|---|
| `fig2a_palette.csv` | 100 阶色标（`value` 0→0.6，`r/g/b` 0–255） | 从原图 Fig. 2a 右侧色条 `Correlation` 逐像素纵向采样 | `R/figures/Fig2a_correlation.R` |
| `fig2a_dots.csv` | 56 个行注释圆点的颜色（`position` 1–56，`axis_label_paper` 原图编号） | 从原图 Fig. 2a 右侧 56 个圆点逐个取色；顺序即矩阵行顺序（上→下） | 同上 |

> 为什么要单独存成 CSV：原脚本依赖一个 `ref/fig2a_style.R`（里面硬编码 `PAL_100` / `DOT_56`）。
> 换成 CSV 之后，颜色既**可核对**（能直接和原图色条对照），又**不依赖任何外部 R 文件**。
>
> **Fig 1b / 1c / 2b 不需要本目录的任何文件。** Fig 1b / 1c 只读主数据对象；
> Fig 2b 的家族配色是可选文件（见第 2 节）。

## 3. 想自己从原图重新取色？

思路（也是本项目实际采用的）：

1. 用 `pdftotext -bbox` 或 PyMuPDF 拿到目标图区域的**矢量矩形**（色条、圆点、色块都是 `rect` 或 `circle`，带 `fill` 颜色）；
2. 按 x/y 坐标把元素排成有序序列（例如色条从上到下、圆点从第 1 行到第 56 行）；
3. 记录每个元素的 RGB，按位置赋一个 `value`（色条取 0→0.6 线性等分）；
4. 存成 CSV（列名 `value,r,g,b` 或 `position,axis_label_paper,r,g,b`）。

`R/figures/Fig2a_correlation.R` 里 `colorRamp2(seq(0, 0.6, length.out = 100), PAL_100)`
就是把 `fig2a_palette.csv` 的 100 个 RGB 直接当作色带锚点 ——
取色与重绘用的是同一张表，颜色不会跑偏。
